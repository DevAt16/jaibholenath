# Data Policy

Phase 1 uses Google Places API as a discovery source only. It does not produce an
official census of Shiva temples in India.

## Stable External Reference

Google Place ID is stored as the stable external reference for each discovered
candidate. It is used for deduplication and for later review workflows.

## Discovery Data

API data is stored to help discover and review likely temple candidates. Names,
addresses, and coordinates from Google Places should be treated as candidate
signals, not final cultural or historical truth.

## Verification Later

Final temple knowledge should be verified later from multiple sources such as
official records, temple trusts, local directories, field review, community
submissions, publications, and other public sources.

## Reporting Language

Phase 1 reports discovery counts:

- total discovered candidates
- unique Google Place IDs
- high-confidence Shiva temples
- medium-confidence Shiva temple candidates
- low-confidence possible temples
- duplicates removed
- state-wise counts
- district-wise counts

These reports must not be described as exact real-world temple counts or as an
official temple census.
