## Scope and how to use this pack

Two existing candidates per district, selected before research for identifiable names and varied urban/rural evidence challenges; not a representative sample. No substitution for easier famous sites.

Keep the original candidate and Place ID. Review each linked source, then use the admin editor to record supported fields and your own rationale. Leave reviewed coordinates blank until checked. An institutional name entry alone does not certify a current location. A directory match alone does not prove source independence. Do not import the companion research JSON directly into the review API; it is an evidence manifest, not an API payload.

The target remains 30 documented reviews across the pilot, with outcomes reported separately. This first six-record pass tests the method; it does not count as 30 completed decisions. A suggested needs-evidence state is not a rejection.
